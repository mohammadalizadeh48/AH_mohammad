راهنمای اجرای محمد استودیو

نیازمندی‌ها: Python 3.10 یا جدیدتر

۱) در پوشه پروژه اجرا کن: pip install -r requirements.txt
۲) برای پنل مدیریت متغیر ADMIN_PASSWORD را تنظیم کن.
۳) برای اجرای پایدار، FLASK_SECRET_KEY را روی یک مقدار تصادفی و ثابت تنظیم کن.
۴) اجرا: python app.py
۵) سایت: http://127.0.0.1:3000
۶) پنل مدیریت: http://127.0.0.1:3000/admin

ابزار QR:
- ساخت QR از متن و لینک در مسیر /api/qr/generate انجام می‌شود.
- بارگذاری عکس یا ویدیو و ساخت QR لینک آن در /api/qr/upload انجام می‌شود.
- خواندن QR از تصویر در /api/qr/decode انجام می‌شود.
- فایل‌های بارگذاری‌شده در پوشه uploads ذخیره می‌شوند. برای سرورهای ابری، مسیر MEDIA_UPLOAD_DIR را به یک فضای ذخیره‌سازی پایدار و قابل نوشتن متصل کن؛ اگر دیسک میزبان موقت باشد، فایل‌ها با راه‌اندازی مجدد یا انتشار مجدد ممکن است از بین بروند.
- سقف حجم هر درخواست ۲۵ مگابایت است. فرمت‌های عکس PNG/JPG/WEBP/BMP/GIF و ویدیوی MP4/WEBM/MOV/M4V پذیرفته می‌شوند.
- QR مربوط به عکس و ویدیو حاوی لینک عمومی فایل است؛ بنابراین برای باز شدن روی گوشی دیگران، سایت باید از اینترنت و HTTPS در دسترس باشد.

نکته امنیتی: پنل بدون ADMIN_PASSWORD فعال نمی‌شود. برای میزبانی عمومی از سرور توسعه Flask استفاده نکن و از WSGI server مناسب استفاده کن.
